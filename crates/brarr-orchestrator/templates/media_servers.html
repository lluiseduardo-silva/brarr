Adicionar servidor

Jellyfin e Emby usam uma API key criada no painel do próprio servidor (Painel → Avançado → Chaves de API). O Plex não: a credencial é um token de conta, e ela vem do botão entrar com o Plex na linha do servidor — cadastre sem preencher nada aqui e faça o login depois. Colar um token à mão também funciona, e é o resgate para quando o navegador atrapalha.

Mapeamento de caminhos

O aviso diz onde olhar, então o caminho precisa estar escrito do jeito que o media server enxerga. Se o brarr e ele montam a mídia no mesmo lugar, não há nada a configurar.
