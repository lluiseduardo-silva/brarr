Conectividade

Workers

Cadência do poller que checa *arr/wanted. Mínimo 60s.

TMDB

{% if values.tmdb_configured %} configurado {% else %} sem credencial {% endif %}

Fonte de metadados da biblioteca. Aceita tanto o read access token (v4) quanto a API key (v3) — o formato é detectado sozinho. Deixe o campo em branco para manter a credencial atual.

Histórico & retenção

Quantos dias de decisions/searches manter antes da poda automática. 0 = manter pra sempre. Decisões já empurradas ao *arr são preservadas.

Import

Como o arquivo sai da pasta do cliente de download e entra na biblioteca.

Hardlink são dois nomes para os mesmos bytes: não gasta disco e o cliente continua semeando — que é obrigatório em tracker privado. Só funciona dentro do mesmo filesystem; quando a biblioteca está em outro disco, o brarr cai para cópia sozinho. Mover libera o espaço na hora e mata o seed. O brarr nunca sobrescreve um arquivo existente e nunca remove nada do cliente.
